# v0.8.12 发布清单

日期：2026-09-07；状态：发布前审查快照（远端发布状态以 Actions / npm 记录为准）。

## 范围

- 导入页显示已解析数据的来源、文件名和行数；不再以原生文件选择框的空值判断是否导入成功。
- 文件选择后自动解析；“解析粘贴内容”仅处理新文本，避免成功上传后误报缺少数据。
- 支持再次选择同一文件；解析失败保留已有数据。新粘贴内容需解析或清空后才能进入下一步。
- 仅恢复摘要而没有完整明细时明确提示重新导入。不改变 Host、QCC 调用、补全和导出契约。

## 验收与发布

- 223 项测试，以及 lint、文档版本、市场材料、打包检查。
- 深浅色 × 五种视口共 10 组隔离 Chromium 回归，覆盖自动解析 23 行、重复选文件、失败替换和下一步校验。
- 浏览器使用合成数据，不调用真实 QCC；本次不自动升级或重启本机 DSH。
- release mode 检查通过后提交 main，等待 Linux Node 22/24、Windows Node 24 和 Chromium CI 通过，再推送 annotated Tag。
- Tag 工作流以 OIDC 发布 npm provenance 并创建 GitHub Release；发布后核对版本、latest、Tag 和包内容。

## 升级与回滚

升级至 0.8.12 后完全重启 DSH。选择文件即自动解析，核对清单后直接进入“规则与体检”，无需再点击文本解析。

已有下载制品不改写。需要回滚时安装 dsh-data-cleaning-agent@0.8.11 并重启 DSH；旧版可能继续显示此次修复的导入状态误报。
