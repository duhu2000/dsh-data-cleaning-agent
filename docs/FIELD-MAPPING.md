# 字段映射推荐

参考「DSH插件-【AI填表 智能体】」的原表字段选择器：推荐需可解释、可修改，按维度分组查找，筛选不能清除已选字段。

## 规则与边界

- 自动映射：当前 128 个可补全字段的标准中文名、英文键，以及明确别名。全角字符、大小写和空格/下划线/连字符统一后比较。不依赖模型，不外传原表，不消耗 QCC 调用。
- 推荐确认：地址推荐注册地址/通信地址/开票地址；网址推荐官方网站；开业时间推荐成立日期，但两者含义可能不同，必须确认。行业区分国标行业与企查查行业，不引入一级/二级行业等不存在的字段。
- 重复冲突：多列同时匹配同一目标时，暂不自动选择。用户选择一列后，其他列显示已占用；必须先释放原映射才能换列，不隐式抢占。
- 未知表头保持未映射，不再把未知第一列强制当成企业名称。无表头文本名单由解析器产生明确的「主体标识」列，继续兼容原流程。
- 映射选择器可折叠、搜索中文/英文键/别名、按工具维度分组。Escape 收起并恢复焦点。补充自动映射只填尚未映射且目标未占用的列，保留人工选择。
- 字段映射定义输入列含义；下方「输出字段」定义补全范围，二者不联动扩大。匹配仍需企业名称、信用代码或注册号至少一个锚点。联系电话为输入校验字段，首选联系电话是 QCC 补全字段，保留区别。

## 重复表头与旧任务

### 结果回填

已选补全字段按照已确认的映射回填原列，空字符串、纯空格、null/undefined 才视为空；0、false 和已有文本保留。未选择的字段不参与回填；没有原列映射的已选字段继续新增列。多候选/失败行不使用候选值补空。原列及其顺序、重复列、未映射列全部保留，原始查询行不在投影时修改。

预览、结果 CSV/XLSX、异常清单使用同一补空规则。已经生成的耐久下载制品保持不可变，升级不会改写历史 Excel；新任务采用此规则。旧任务未生成制品且映射已确认时，生成的新制品可以使用其已有查询结果，无需因为导出而再次查询 QCC。

CSV/XLSX 从本次改动开始为重复表头添加 `（重复列 N）`，并避开原表已有同名列，所有原值独立保留。旧任务中已经被同名键覆盖的值无法凭空恢复，请从原始文件新建任务重新导入。已保存映射不会在恢复或重绘时自动替换；规则确认、质量体检及补全流程保持不变。
