# 0.9.15 — Host 驱动的单向工作流

本版本发布 0.9.14 已完成但因 CI 可移植性断言未能进入 npm 的功能内容：

- Host `flow.currentStage`、`stageAccess` 与 `allowedActions` 负责业务流程和操作权限，Client 独立维护查看节点。
- 未来节点提供明确锁定反馈；已完成节点可查看，但不挂载改变业务状态的操作。
- 导入完成后保留完整名单核验，主操作位于表格底部；确认后进入规则与体检。
- Agent-owned 高层执行可以按 Host 状态跨过中间 UI 节点，不拆分 QCC 调用、确认、计费、幂等或隐私边界。
- 紧凑状态区展示节点、来源、时间、任务范围和明确结果计数。
- 保留提交接纳去重、后台 Session 隔离和用户手动收起保护。
- 工作流契约以 `flowVersion` 和显式访问投影保留未来回退扩展空间，本期不增加回退 Tool 或任务版本模型。

发布门禁已在 UTC 环境通过 290 项自动化测试，并通过浅色/深色共 10 组 Chromium 布局矩阵及 3 组制品预览回归。升级后完整重启 Profile 并新建清洗 Session；旧 Session 迁移不在本版本验收范围。
