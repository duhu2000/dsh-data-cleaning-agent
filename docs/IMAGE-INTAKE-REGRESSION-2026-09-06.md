# 图片入口回归记录（2026-09-06）

## 本轮问题与修复

- 提示词向导默认文本页未接管图片粘贴，Modlens 将图片转成本地路径后被当作企业名。现由 window capture 在本插件数据来源页接管实际图片，切换图片识别并显示预览；纯文本图片路径明确拒绝。
- 右侧工作台文件选择器仅支持表格。现支持 PNG/JPEG/WebP，转入当前会话的图片向导，共用暂存、预览、字段选择与 QCC 文档解析链路，不把图片发送到表格解析接口。
- 回填增加原生输入机提交阶段检查及草稿读回验证。提交中保留图片与设置；不会用 DOM 操作强行解除 DSH 的发送禁用状态。
- 保留仓库同时进行的会话入口与归属修复，合并进入 0.8.4 发布范围。

## 安装后仍需验收

1. 从数据清洗补全菜单新建独立会话，在默认“粘贴企业名单”页直接粘贴截图，确认进入图片页并显示可放大缩略图。
2. 完成匹配规则、字段选择与说明回填，确认主体不是文件路径；原生图片附件释放后，DeepSeek 文本模型可发送 OCR 任务说明。
3. 检查发送箭头/Enter；若仍禁用，应检查 DSH 会话就绪、运行阶段、composer block 和模型配置。当前无现场证据证明这项已消失。
4. 右侧新任务选择 PNG/JPEG/WebP，确认进入同会话图片向导；无接收方时应留在右栏并提示。
5. 连接可读取本地暂存文件的 qcc-document-mcp，执行真实 parse_document/get_parse_result，核对两企业名单、所选字段、中文 XLSX。
6. 普通新会话及其他智能体入口不显示本插件内容；文字粘贴行为不受影响。
