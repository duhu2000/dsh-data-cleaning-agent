# 0.9.14 — Host 驱动的单向工作流

- Host `flow.currentStage`、`stageAccess` 与 `allowedActions` 成为业务流程及操作权限的唯一依据；Client 独立维护当前查看节点。
- 五步导航阻止越级操作：未来节点点击后说明解锁条件，已完成节点可查看但不挂载会改变业务状态的控件。
- 导入完成后保留完整名单核验视图，主操作固定在表格底部；确认后进入规则与体检。
- Agent-owned 高层执行可一次跨过匹配、补全与交付阶段，Client 按 Host 最新状态同步，不拆分 QCC 调用、确认、计费、幂等或隐私边界。
- 刷新与重新挂载从 Host 任务恢复真实节点；运行时名单缺失时只展示可恢复信息，不自动重复查询或扣量。
- 状态区收缩为紧凑流程摘要，展示真实节点、任务状态、来源、时间、任务范围及有意义的结果计数。
- 保留 0.9.13 的提交接纳逻辑：草稿回填和失败发送不展开，后台 Session 不抢占界面，手动收起不被轮询重新展开。
- 当前版本仍不提供流程回退；契约通过 `flowVersion` 与显式访问投影保留未来扩展空间，不引入任务版本或通用事件框架。

发布验收通过 290 项自动化测试。升级后完整重启 Profile 并新建清洗 Session；旧 Session 迁移不在本版本验收范围。
