# dsh-data-cleaning-agent v0.8.16

## 本版改进

- 提示词向导与右侧工作台统一：上传显示完整分页清单及空白数量，确认原列映射后自动形成补全范围。
- 映射状态同时提供颜色和文字：绿色已通过、琥珀色待人工确认、红色未匹配。模糊候选不自动当作已确认。
- 多个原列可确认使用同一非主体字段；查询字段去重，分别补空，保留非空值、0 与 false。企业名称、信用代码、注册号各保留唯一匹配主列。
- 已映射字段无需重复选择；额外字段目录默认折叠。修复 Host 草稿把新范围覆盖成默认五字段的问题。
- 草稿生成前检查 Host 协议能力，发现新页面配旧进程时提供中文升级提示；生成不查询，发送才执行。

## 验收与边界

233 项自动化测试通过，深浅色 × 5 种视口的 10 组隔离 React/Chromium 回归通过。使用合成数据，不以此声称已完成真实 QCC 查询或本机安装验收。详见 [映射验收](TEMPLATE-MAPPING-ACCEPTANCE.md)。

本版只改数据清洗补全仓库，不改 AI 填表及共享字段契约包版本。未知或不支持的字段保留原列，不猜测填充。

## 升级与回滚

1. 保存或导出现有任务，备份任务目录，并记录现有精确版本。
2. 停止对应 DSH Profile，安装：`dsh plugin --profile web add dsh-data-cleaning-agent@0.8.16`。
3. 完整重启 DSH 并刷新页面；仅刷新浏览器不足以更新旧内存 Host。
4. 回滚可安装 `dsh-data-cleaning-agent@0.8.15` 并恢复升级前任务副本。旧版不支持新增多列共享字段映射，不能直接用旧版编辑新版多列映射任务。

历史导出文件不会被自动改写。
