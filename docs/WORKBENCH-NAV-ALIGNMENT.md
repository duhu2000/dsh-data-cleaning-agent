# 右侧工作台阶段菜单对齐

日期：2026-09-07。开发基线：v0.8.8；目标发布版本：v0.8.9。本文件记录发布前验收快照，实际发布结果以 Git Tag、Actions 与 npm Registry 为准；不更新已安装的 DSH。

## 设计依据与范围

以共享 [DSH-UX-001 v1.1.2](../../../../AI-设计/DSH智能体开发交互规范方案.md) 的 UX-17 / UX-37 和 [企查查蓝 Mockup](../../../../AI-设计/DSH智能体_企查查蓝_UI_Mockup_v1.1.0.html) 为准，参考招投标工作台截图；不复制、修改共享规范。

- 保留“当前任务 / 任务历史”管理层。
- 当前任务内五阶段使用单行等宽分栏，上方线性 SVG 图标、下方单行短标题；不再显示数字序号。阶段按钮不承载描述、统计和执行状态。
- 使用列分隔线、浅蓝选中底色、蓝色文字和底部蓝线；与现有企查查蓝深浅色令牌一致。
- 窄屏不改成两行，不产生横向菜单滚动；过长标题在列内省略，完整名称通过可访问名称与悬停提示保留。
- 说明仍在折叠“使用说明与任务流程”和各阶段正文中。菜单只切换视图，原生对话框、发送、图片识别、字段目录及 Host 执行契约不变。

## 验证

执行 `npm run check` 和 `npm run test:ui`。后者使用真实 React / Chromium 与隔离 Host fixture，不连接真实 DSH 或 QCC；运行依赖说明见脚本文件头。

本轮结果：`npm run check` 全部通过（214 项测试、lint、文档、市场材料与打包白名单检查）；`npm run test:ui` 10 组全部通过，未出现页面脚本错误或隔离契约外请求。已人工查看桌面浅色与 320px 深色菜单截图。

回归包括浅色/深色各 1440×900、1024×768、390×700、320×700、900×500：五列等宽同排、图标位于文字上方、分隔线和选中底线、超长标题不撑宽、普通与展开布局、菜单切换不改变任务，以及原有向导/回填/字段搜索/业务隔离检查。

截图及机器结果位于忽略的 `_scratch/ui-layout/`，阶段菜单截图以 `stage-menu-` 开头。该验收是本地组件与布局验收，不等同于已安装 DSH 的真实端到端验收。
