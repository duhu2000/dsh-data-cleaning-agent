## 实现

- 左边缘 8px 分隔条，悬停/聚焦/拖动蓝线；向左增宽，向右减宽。
- 320px 最小宽度，上限为宿主会话可用区域减去 420px；监听窗口和宿主区域尺寸，移动端或区域不足两栏时全屏并隐藏分隔条。
- 指针捕获，Escape / pointercancel / 失焦取消拖动；左右键 16px，Shift 48px，Home/End 边界，双击恢复默认。
- 展开为快捷预设，收起恢复手动值；展开后拖动转回手动模式；关闭重开在本插件客户端生命周期内保留偏好，不跨刷新存储。
- 宿主会话滚动区只设置自有让位变量并保存原值；关闭/卸载还原，监听解除。拖拽不改任务、字段和调用范围。
