## 兼容性与数据边界

- 旧 industry_category / qcc_industry ID 保留：旧文本原样输出；新对象按明确层级标注串联，禁止直接 String(object)。独立层级只取对应叶子，不把旧文本认定为某层级，也不从其他层级补缺。
- 地区字段来自嵌套“地区信息”，不从所属地区/注册地址拆分；地区代码保留字符串与前导零。不同主体可能不返回这些字段，缺失留空。
- 企业规模取简介“企业规模”（上游大型/中型/小型/微型）；原 company_size 仍是工商“人员规模”，不能互相回填。
- 主营产品是名称数组，按原顺序以中文分号合并单元格，不展开企业行、不重排、不去重。当前服务只请求前 10 项，空数组也可能来自不支持主体或补充接口异常，不能据此判断企业没有产品。
- 原表非空值保护、只回填选定字段、来源审计和客户 XLSX/任务报告分层保持不变；主结果不增加本次未选字段。
