# 0.8.14：体检后直接生成任务说明

正式工作台流程：导入与核验 → 规则与体检 → 主体匹配页生成可编辑任务说明 → 阅读/备注/发送 → 查询、候选核验与下载。

- 删除正常流程的手动连接检测、手动估算按钮及初始额度复选框。
- Host 使用与执行阶段相同的去重、字段工具路由及上限计算；草稿包含主体数量、调用上界和账号说明。生成阶段只读取工具注册表，不查询企业、不消耗 QCC 调用。
- 缺少工具时提示到 MCP 连接器配置并重新生成；超过 Host 批量/调用限制时明确阻止，不静默截断。现有 Host 100 行/300 次默认上限不变，前端不再复制该计算。
- 发送才执行；执行时重新校验。多候选和失败重试仍需显式继续查询确认，不自动扩大范围。修改名单或字段需返回工作台重新生成，备注可直接修改。
- 不改变任务 schema、历史制品或共享字段契约；不影响 AI 填表包。旧版直接执行 API 的确认及幂等门保持不变。
- 升级需重启 DSH；内存任务请先下载结果。回退 0.8.13 时保持原任务数据与配置备份，不删除会话或制品。
