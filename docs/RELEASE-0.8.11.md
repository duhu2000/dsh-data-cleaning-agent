# v0.8.11 发布清单

日期：2026-09-07；状态：发布前审查快照（远端发布状态以 Actions / npm 记录为准）。

## 范围

- 字段映射：128 个字段的标准中文名、英文键和明确别名自动匹配；多义表头推荐确认；重复目标人工选列；折叠、分组搜索、Escape 焦点恢复。
- 补全回填：已选且已映射字段只补原列空值，非空文本、0、false 不覆盖；没有对应列的已选字段新增。预览、CSV/XLSX 与异常清单保持一致。
- 重复表头：CSV/XLSX 添加无碰撞列键，独立保留每列原值。
- 保留既有 QCC 工具范围、费用确认、任务持久化契约与原生发送机制；不自动重启/升级本机 DSH。

## 验收

- 222 项测试、lint、文档版本一致性、市场材料及打包检查。
- 深浅色 × 五种视口共 10 组隔离 Chromium 回归。
- 用户提供的 23 行 Excel 只读重放：三项明确映射共 69 个空白单元格正确回填；原文件未改写，客户明细未提交，未发起真实 QCC 请求。
- 发布前使用 release mode 再跑完整门禁；main 推送后须等待 Linux Node 22/24、Windows Node 24、Chromium CI 成功再推送 annotated Tag。
- Tag 工作流通过 OIDC 发布 npm（provenance），并创建 GitHub Release；回读 npm latest、Tag 与包内容。

## 升级与回滚

安装 0.8.11 后完全重启 DSH，新建任务验证映射、原列回填和导出。已有耐久制品不改写；旧任务若发生过重复表头覆盖，需要重新导入原文件，不能从已丢失的值恢复。

需要回滚时安装 dsh-data-cleaning-agent@0.8.10 并重启 DSH。旧版不具备此次智能映射和原列补空能力；不会移动 Tag 或覆盖已发布 npm 版本。
